# Nightout Mobile

Aplicativo mobile desenvolvido com [Expo](https://expo.dev) e React Native.

## Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/) (já vem com o Node.js)
- [Expo Go](https://expo.dev/go) instalado no celular (para testar no dispositivo físico) **ou** um emulador Android/iOS configurado

## Instalação das dependências

Na raiz do projeto, execute:

```bash
npm install
```

## Iniciando o projeto

Após instalar as dependências, execute:

```bash
npm run dev
```

Isso abrirá o **Expo Developer Tools** no terminal. A partir daí você pode:

- Pressionar **`a`** para abrir no emulador Android
- Pressionar **`i`** para abrir no simulador iOS (somente macOS)
- Pressionar **`w`** para abrir no navegador web
- Escanear o **QR Code** com o aplicativo Expo Go no seu celular

## Scripts disponíveis

| Comando | Descrição |
|---|---|
| `npm run dev` | Inicia o servidor de desenvolvimento Expo |
| `npm run build:web` | Gera o build para web |
| `npm run lint` | Executa o linter no projeto |
